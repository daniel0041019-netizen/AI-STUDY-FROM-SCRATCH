## 📌 Project Overview
군 복무 중 사지방(사이버지식정보방) 제한된 환경 속에서 시작한 **1인 AI 엔지니어링 빌드업 프로젝트**입니다. 

1. **Phase 1 (Theory & Core Coding):** 《핸즈온 머신러닝》 및 《딥러닝의 정석》을 바탕으로, ML/DL 기초 수학 이론 및 핵심 모델 구조(CNN, RNN, U-Net, WaveNet, Transformer)를 PyTorch로 밑바닥부터 하드코딩하여 원리를 다졌습니다.
2. **Phase 2 (Production AI Systems):** 단순 아키텍처 구현을 넘어 **LLM API 연동, Structured Outputs(Pydantic), Advanced RAG, AI Agents, LLMOps 및 배포 파이프라인**으로 외연을 확장하여 실무 환경에 즉시 적용 가능한 생산성 높은 시스템을 구축합니다.
